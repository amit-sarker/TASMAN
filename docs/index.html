Knowing Whom to Trust is not Enough

The Trust–Agreement Gap in Repeated Multi-Party LLM Negotiation

Amit SarkerMoumita ChoudhurySaaduddin MahmudShlomo Zilberstein
University of Massachusetts Amherst
Paper Code Watch a game BibTeX

Five parties negotiate a package of five issues. They take turns proposing, and a proposal passes with 4 of 5 votes. Each game lasts up to 15 rounds, and the same five parties play 20 games in a row. The trust each party builds in the others during one game shapes how it plays the next, and that trust is the only thing that carries over between games. Illustrative animation, not a real negotiation game.

TL;DR

Strong at trusting. Weak at using it.
